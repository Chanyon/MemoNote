# 白板笔记（Whiteboard Notes）

一款AI开发，使用 Rust 与 [GPUI Kit](https://crates.io/crates/gpui-kit) 构建的本地无限画布笔记应用。笔记直接保存为 Markdown 或纯文本文件，白板布局保存在同名的 `.board.json` 中，适合整理灵感、阅读笔记和思维导图。

## 功能

- **无限画布**：自由平移、缩放，自动适应内容。
- **浮动滚动条**：画板右侧和底部显示浮动滚动条，可拖动平移画板；可在设置中开启或关闭。
- **本地笔记库**：按目录管理 Markdown / 纯文本笔记，支持新建、重命名和删除。
- **文本卡片**：支持 Markdown 与纯文本渲染，可拖拽、缩放和旋转。
- **自定义连接**：在文本卡片或笔记卡片之间创建带方向箭头的连接线，可在节点右键菜单中清除该节点的所有连接。
- **思维导图**：添加根节点与子节点，拖拽子树，自动避让重叠；长主题自动换行并调整节点高度。
- **图片卡片**：从剪贴板粘贴图片，随笔记一起保存在本地。
- **多选与布局**：`Shift` 框选思维导图节点，支持批量拖动。
- **卡片锁定**：工具栏或右键菜单可锁定 / 解锁任意卡片；锁定卡片会显示锁图标，并禁止删除。
- **删除卡片**：文本、思维导图、图片和笔记主卡片都可以删除；删除笔记主卡片后笔记文件仍会保留，可继续通过「编辑」修改笔记内容。
- **实时预览**：可在设置中开启分栏编辑，左侧编辑 Markdown / 纯文本，右侧实时显示渲染效果。
- **AI 写作**：在设置中配置 OpenAI Chat Completions 兼容服务（服务地址、API Key、模型）。笔记和文本卡片右上角都有机器人按钮；AI 输入框可拖动调整高度，返回内容会流式追加到编辑区，不会覆盖之前生成的内容，并自动滚动跟随最新内容。
- **AI 画板文档**：工具栏的「AI 生成」可把主题拆分为多张文本卡片、思维导图和配图，并自动添加节点连接。生成窗口可拖动，输入框可拖动下边缘调整高度；生成时会显示 AI 思考过程和生成阶段，支持取消。AI 优先输出 SVG 图表，由 GPUI-KIT 直接渲染，无需图片模型；其他配图使用设置中的图片生成模型，失败时会自动跳过。
- **界面定制**：简体中文 / English 切换、亮色 / 暗色模式、预设主题和自定义配色。
- **本地优先**：不依赖账号或云端，所有数据保存在本机。

## 运行

环境要求：Rust 1.85+（使用 Rust 2024 edition），当前主要面向 Windows 10/11。

```powershell
# 开发运行
cargo run

# 构建 release 版本
cargo build --release
```

Release 可执行文件位于 `target/release/whiteboard-notes.exe`。Release 构建会隐藏 CMD 控制台和原生 Windows 标题栏，使用应用内自绘标题栏；Debug 构建则保留控制台和原生标题栏，便于调试。

## 快捷键

| 快捷键 | 功能 |
| --- | --- |
| `Ctrl+N` | 新建笔记 |
| `Ctrl+Shift+N` | 新建目录 |
| `Ctrl+E` | 编辑选中的卡片 |
| `Ctrl+V` | 粘贴剪贴板图片 |
| `Delete` / `Backspace` | 删除选中节点 |
| `+` / `-` | 放大 / 缩小 |
| `0` | 适应画布内容 |
| `Esc` | 取消选择或关闭弹窗 |

鼠标操作：拖动画布空白处平移，滚轮平移，`Ctrl+滚轮` 缩放，双击卡片编辑，右键节点打开菜单，`Shift+拖拽` 框选思维导图节点。选中文本节点后可点击工具栏的“连接”，再点击另一个文本节点建立关系；右键节点可选择“删除所有连接”。

## 数据与配置

- 笔记默认保存在 `文档\WhiteboardNotes`，可在设置中修改保存目录。
- 每篇笔记对应同名的 `.board.json` 文件，粘贴的图片位于 `.assets` 目录。
- 应用配置保存在 `%APPDATA%\WhiteboardNotes\settings.json`。
- 调试或自动化测试时可使用环境变量：
  - `WHITEBOARD_HOME`：覆盖默认笔记目录。
  - `WHITEBOARD_CONFIG`：覆盖配置文件路径。

## 技术栈

- **Rust**：应用逻辑与文件存储。
- **GPUI Kit**：桌面 UI、主题和交互组件。
- **Serde / serde_json**：白板与配置序列化。
- **image / arboard**：图片处理与剪贴板。
- **ureq**：调用自定义 OpenAI 兼容 AI 服务。
- **uuid**：节点标识。

## 项目结构

```text
src/
  main.rs      应用启动、窗口选项与主题初始化
  app.rs       界面、画布交互、思维导图、编辑器与文件树
  ai.rs        AI 服务地址、请求构建与流式响应解析
  model.rs     笔记数据模型、白板持久化与文件操作
  settings.rs  配置、语言、主题预设、AI 服务商与保存路径
```
